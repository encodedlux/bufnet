# Installation

BufNet can be installed through [Wally](https://wally.run/) or [Pesde](https://pesde.dev/), depending on your preferred package manager.

## Wally

:::tabs
==wally.toml
```toml
bufnet = "encodedlux/bufnet@0.1.0"
```
:::

## Pesde

:::tabs
==pesde.toml
```toml
bufnet = { name = "encodedlux/bufnet", version = "^0.1.0" }
```

==pesde-cli
```bash
pesde add encodedlux/bufnet
```
:::
